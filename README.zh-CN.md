# codex-session-renamer

[English](README.md) | [中文](README.zh-CN.md)

手动修复近期 Codex 根会话标题，统一生成 `YYYY-MM-DD｜核心内容总结`。按最后对话时间从新到旧扫描，遇到首个全合规批次就停止。

> **免责声明。** 只要一个批次中存在不合规标题，就会重命名该批全部会话，且没有内置回滚功能。使用前请先阅读 [SKILL.md](SKILL.md)。

## 它能做什么

| 能力 | 行为 |
| --- | --- |
| 语义化标题 | 根据完整会话的目标演进识别核心主题，再用实际结果补充。 |
| 最后对话日期 | 按系统当前时区，在每个标题前加入对应会话最后一次有效对话的日期。 |
| 手动增量执行 | 每批检查 20 条；发现任一不合规标题就重命名整批，首个全合规批次立即停止。 |
| 按会话选择语言 | 默认让每个标题跟随对应会话的主要用户语言。 |
| 显式指定语言 | `language=<language>` 可强制所有标题和用户可见输出使用同一种语言。 |
| Token 控制 | 运行环境支持模型选择时，优先使用低消耗模型，并只读取精简的会话上下文。 |
| 范围保护 | 排除 ChatGPT 对话和子代理会话。 |
| 不创建自动化 | 只有你明确调用 Skill 时才会执行。 |

## 命名与语言规则

标题格式：

```text
YYYY-MM-DD｜核心内容总结
```

日期取自最后一条有效用户消息或助手回复，执行过程中的进度播报不会改变日期。如果找不到有效的对话时间，则回退到创建日期。

未指定语言时：

- 每个标题使用对应会话自己的主要用户语言；
- 进度信息和最终报告使用当前触发 Skill 的对话语言；
- 如果会话语言不明确，则依次回退到当前标题语言、触发会话语言。

显式指定语言时：

```text
language=English
language=zh-CN
language=ja
```

指定语言会同时作用于所有新标题和所有用户可见输出。项目名、产品名、代码标识符和通用技术术语会在合适时保留原文。

## 环境要求

- OpenAI Codex，并且可以使用本地会话管理工具。
- 本地存在 `~/.codex/state_5.sqlite` 会话目录。
- Node.js 20 或更高版本。
- `sqlite3` 已加入 `PATH`。
- 已在 macOS 上测试。

## 告诉 Codex 安装

直接告诉 Codex：

```text
请从 https://github.com/RuntianLee/codex-session-renamer 仓库根目录安装 codex-session-renamer Skill。
```

Codex 会使用内置的 Skill Installer，把 Skill 安装到 `$CODEX_HOME/skills`。安装完成后，下一轮对话即可使用。

## 使用方法

### 自动判断语言

```text
使用 $codex-session-renamer 修复近期 Codex 根会话标题。
```

### 强制使用同一种语言

```text
使用 $codex-session-renamer language=English 修复近期 Codex 根会话标题。
```

可将 `English` 换成语言名称或 BCP-47 标签，例如 `zh-CN`、`ja`。

> **重要：** 如果某批存在一个不合规标题，该批所有会话都会被重新总结和重命名。该 Skill 不提供定时模式、dry-run 或自动标题备份。

## 工作原理

1. 按最后对话时间倒序排列根会话。
2. 每批只用数据库元数据轻量检查 20 个标题，不打开会话正文文件，并直接返回 `batchCompliant` 和 `noncompliantCount`。
3. 如果 20 个标题全部符合日期和主题规则，立即停止。
4. 如果存在任一不合规标题，再读取该批精简上下文，并重命名整批 20 个会话。
5. 对归档任务临时解除归档，重命名后恢复原归档状态。
6. 继续下一批，直到遇到全合规批次或到达末尾。

## `agents/` 和 `scripts/` 是做什么的

### `agents/`

这个文件夹里只有 `openai.yaml`，负责告诉 Codex 如何展示这个 Skill：

- 显示名称；
- 简短说明；
- 启动时显示的示例提示词。

它用于改善 Codex 中的使用体验，不负责扫描或重命名会话。

### `scripts/`

这个文件夹存放检查标题并为 Codex 准备会话信息的辅助脚本。

简单来说，脚本会：

1. 从 Codex 本地会话列表中找出普通根会话；
2. 跳过 ChatGPT 对话和子代理会话；
3. 打开本地保存的会话，只保留最后有效对话日期、当前标题、从会话全过程分层抽取的最多四条用户要求，以及最后一条非进度类结果；
4. 去掉附带的 Skill 原文、代码块和页面标记等无关内容；
5. 支持轻量 `--check-only` 元数据检查，只为需要重命名的批次打开会话文件并返回完整精简上下文。

脚本只读取本地文件。它不会自己决定标题、修改数据库或执行重命名。真正的标题写入由 Codex 官方会话工具完成。

## 安全与隐私

| 范围 | 保证 |
| --- | --- |
| 会话内容 | 只在本地读取，用于提取精简的命名上下文。 |
| 数据库 | 只查询会话元数据，不直接向 SQLite 写入标题。 |
| 重命名 | 使用 Codex 官方会话工具。 |
| 归档任务 | 重命名后恢复原来的归档状态。 |
| 排除范围 | 永不选择 ChatGPT 对话和子代理会话。 |
| 自动化 | 永不创建或更新定时自动化。 |
| 删除操作 | 永不删除会话、消息、记忆或项目文件。 |
